# 电商销售数据分析（E-commerce Sales Analysis）

用 Python（pandas + matplotlib）对 2025 年订单数据做的一次完整分析：从清洗、指标计算到图表和结论建议。用于展示数据分析的基本流程和方法。

## 结论摘要

- 全年 6,000 单，总销售额 **140.6 万元**，扣除退货后净销售额 **126.1 万元**；
- 整体退货率 **10.1%**，客单价 **234 元**，新客占比 **41.9%**；
- 销售高度集中在 **6 月和 11 月**，两个大促节点合计贡献约三成销售额；
- **数码配件**是第一大品类（约 35.2%），**服饰鞋包**退货率最高（约 15.5%）；
- **APP** 渠道销售额最高，**京东**退货率最高（约 12.8%），**线下**退货率最低（约 4.1%）；
- **华东**地区贡献约 34.2% 的净销售额，区域集中度较高。

## 数据说明

数据字段：日期、月份、地区、渠道、品类、单价、数量、金额、是否退货、新客。

**这是按真实电商订单结构生成的模拟数据**，仅用于展示分析方法与流程，不代表任何真实企业经营情况。

## 分析框架

1. 整体趋势：月度销售额与净销售额；
2. 结构拆解：品类销售额占比与退货率；
3. 渠道对比：销售额与退货率双轴；
4. 区域分布：净销售额排名；
5. 结论与建议：备货节奏、退货治理、渠道策略、区域投放。

## 局限与后续

- 缺少退货原因、流量成本、用户 ID，无法做复购和 ROI 分析；
- 后续可补充：退货原因归因、渠道 ROI、RFM 用户分层。
